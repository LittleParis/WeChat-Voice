# 本机微信连接

一次“连接并读取语音”依次执行：检查目录与账号、认证已有密钥或等待首次获取、认证解密必要数据库副本、整理语音索引，全部成功后更新列表。

自动查找只检查常用浅层位置，包括用户文档、OneDrive 文档、磁盘根目录下的 xwechat_files 和已保存位置，不递归扫描磁盘。多个账号需主动选择，自定义目录可手动输入。

首次获取可能要求从微信托盘菜单退出，再手动重新打开并登录；仅关闭窗口不等于退出。等待上限 5 分钟，可以取消。程序不会自动关闭或重新登录微信，微信版本与登录时序会影响是否成功。

获取的候选密钥必须认证所选数据库，原始输出不返回网页。每次使用新副本，全部通过认证、quick_check 和索引后才保存配置并切换。失败或取消不更换原来的列表。旧副本保留，会占用磁盘空间。

配置位于 .private/connection.json。新数据副本、缓存和密钥位于 .private/connections/账号标识/任务标识/。私有目录按当前 Windows 用户限制访问，并被 Git 忽略。

服务只监听 127.0.0.1，检查 Host、Origin、会话 Cookie 和写请求令牌。连接期间不能开始新导出；正在导出时需先完成或取消，以免切换数据源造成选择范围混淆。

工具可提取自己和他人发送的语音，前提是当前电脑数据中仍有对应原始媒体。消息表里有一条“语音消息”不等于媒体 BLOB 已存在；缺失时需要从手机通过官方导出接收，能否补齐取决于手机是否保有该媒体。
