# WeChat Voice · 语音档案

把微信里的原始语音导出成可独立播放的 MP3，并按群聊、联系人、发送人和时间整理。

**普通用户推荐下载 Windows EXE，双击即可打开工具，无需安装 Python、Git 或输入启动命令。**

建议先导出一条语音，确认能播放，再尝试批量导出或手机 App。

## 先了解使用方式

目前的完整流程是：

**电脑版微信中的聊天数据 → 本机网页连接并提取 → 导出 MP3，或生成数据包交给 Android App 管理。**

| 你想做什么 | 需要使用什么 |
| --- | --- |
| 把语音保存成 MP3，在电脑或手机播放器中听 | 电脑 Web 工具即可，无需安装手机 App |
| 在手机中按会话、发送人和日期管理语音 | 电脑生成 ZIP 数据包，再导入 Android App |
| 提取仅在手机微信中保存的历史语音 | 先通过微信官方“导出到电脑”，由同账号电脑微信接收，再使用本工具 |

工具提取的是数据库里的原始语音，不需要逐条播放，也不使用录音。当前提取过程仍然需要电脑；Android App 不能独立读取未 Root 手机的微信私有聊天数据。

## 推荐：下载 EXE，双击使用

1. 打开 [Windows 0.3.0 试用版下载页](https://github.com/LittleParis/WeChat-Voice/releases/tag/v0.3.0)。
2. 下载 **VoiceKeep-0.3.0-windows-x64.exe**；Source code ZIP 是开发者源码，不是启动程序。
3. 将 EXE 放到本机文件夹中，双击运行。首次启动需要稍等片刻，程序会自动打开网页。
4. 在网页中选择微信数据目录与账号，点击“连接并读取语音”。后面的具体操作见下方“首次连接微信”。
5. 使用结束后，点击网页顶部“退出工具”，或在小窗口中点击“退出程序”。关闭网页本身不会停止工具。

程序已内置 Python、网页和处理依赖，不需要另外下载依赖源码，不要求打开终端。网页未自动打开时，点击小窗口中的“打开网页”。端口冲突会自动选择其他可用端口，以实际打开的地址为准。

EXE 连接配置和缓存保存在 **`%LOCALAPPDATA%\VoiceKeep`**，导出结果在其中的 `exports` 文件夹；点击小窗口“导出文件夹”即可找到。更新 EXE 会继续使用原来的数据。这里只提供 Windows 64 位试用版，尚未进行 Windows 代码签名。

首次获取密钥仍可能需要按页面提示手动退出并重新登录微信；EXE 简化的是安装和启动步骤，不能省略微信本身要求的交互。

### 使用前准备

### 电脑端必需

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows |
| 微信 | 已登录本人账号的电脑版微信；当前验证版本为 4.1.13.65 |
| 聊天数据 | 微信 4.x 的 `xwechat_files / db_storage` 数据结构 |
| Python | 3.10 或更高版本；当前已验证 Python 3.10 |
| Git | 用于下载本项目和固定版本的外部依赖 |
| 网络 | 首次下载源码和安装依赖时需要；数据处理在本机进行 |

其他微信版本需要验证兼容性。目前不支持 macOS、Linux、旧版 `WeChat Files` 数据结构或新式 RMFH 官方备份容器的直接解密。

安装好 Python 和 Git 后，打开 **PowerShell**，分别运行：

```powershell
python --version
git --version
```

两条命令都应显示版本号。如果提示找不到命令，先检查安装和 PATH，重新打开 PowerShell 后再试。后面的命令均在电脑的 PowerShell 中执行，不是在网页或微信中输入。

### 目标记录只在手机上时

先使用微信官方的“导出到电脑”功能，将所需会话交给同账号电脑版微信接收。具体入口随微信版本变化，请以当前微信界面为准。

**把聊天记录备份到电脑，不等于这些记录已经进入电脑版微信的本地会话数据库。** 本工具读取的是后者；目前无法直接解析新式加密备份容器。

电脑数据库里有一条语音消息，也不代表对应音频一定保存在电脑上。能否导出取决于原始媒体是否实际存在。

### 下载和安装：只需做一次

### 1. 下载项目

在准备存放项目的目录打开 PowerShell，运行：

```powershell
git clone https://github.com/LittleParis/WeChat-Voice.git
Set-Location WeChat-Voice
```

接下来的命令都在这个 `WeChat-Voice` 文件夹内执行。该文件夹中应能看到 `README.md`、`requirements.txt`、`scripts` 和 `web`。

### 2. 创建 Python 环境并安装依赖

```powershell
python -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install -r requirements.txt
```

等待安装结束。这里直接使用项目的 Python 路径，**不需要额外执行虚拟环境激活命令**。

如果安装报错，请先解决报错再继续，不要跳过失败的安装步骤。

### 3. 下载固定版本的数据库处理依赖

```powershell
git clone https://github.com/freanocank/wechat-decrypt.git third_party/wechat-decrypt
git -C third_party/wechat-decrypt checkout f0b3f9f95dda2d954ee3dbe1d139fb1944a5ecfd
```

这是工具需要的外部源码，保存位置为 `third_party/wechat-decrypt`。只需执行上面两条命令，不需要运行该依赖项目的安装器或其他入口。

`checkout` 提示 `detached HEAD` 是固定到指定提交后的正常状态。不要自行换成其最新分支，以免与当前工具不兼容。

### 启动源码版网页

每次使用时，在项目文件夹打开 PowerShell，运行：

```powershell
& '.\scripts\Start-VoiceLibrary.ps1'
```

看到类似下面的提示后，用浏览器打开 **<http://127.0.0.1:8766/>**：

```text
READY http://127.0.0.1:8766 | 0 voices, 0 chats
```

首次启动没有连接数据，显示 `0 voices, 0 chats` 是正常的。完成连接后会显示已有数据。

- 使用期间保留这个终端窗口；关闭终端会停止网页服务。
- 这个地址只供运行工具的电脑访问，手机不能用它连接电脑。
- 使用结束后，在终端按 `Ctrl+C` 停止服务。

如果 PowerShell 提示禁止运行脚本，可仅在当前终端执行以下命令，再重新启动：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
& '.\scripts\Start-VoiceLibrary.ps1'
```

这个设置只对当前 PowerShell 进程生效。

## 首次连接微信

### 1. 选择聊天数据目录

先打开电脑版微信，并登录需要提取语音的账号。在本工具网页上方找到 **“连接本机微信”**：

1. 点击 **“自动查找”**。如果找到多个数据目录，选择正确的一个。
2. 找不到时，在微信设置中查看聊天数据保存位置，将完整路径填入网页，然后点击 **“检查目录”**。
3. 在 **“微信账号”** 中选择需要处理的账号。

例如下面三种目录都可以识别；这里仅为示例，请填写自己的实际路径：

```text
D:\xwechat_files
D:\xwechat_files\wxid_example
D:\xwechat_files\wxid_example\db_storage
```

不要选择微信程序安装目录，也不要选择 `Backup`。如果检查成功，页面会显示找到的账号，并启用 **“连接并读取语音”** 按钮。

自动查找只检查常用位置，不会遍历整块磁盘。自定义保存目录可能需要手动填写。

### 2. 点击“连接并读取语音”

页面依次显示：

**检查目录 → 验证密钥 → 准备数据 → 整理语音**

密钥处理已经整合进这个按钮，不需要你手动查找、复制或填写密钥。

| 页面情况 | 你需要做什么 |
| --- | --- |
| 已有有效密钥 | 无需重登，等待数据准备完成 |
| 提示退出并重新打开微信 | 按下方顺序操作；不要提前退出或反复点击连接 |
| 提示读取失败或超时 | 查看具体提示，修正后重试；当前兼容性无法保证覆盖所有微信版本 |

**首次需要重登时，按这个顺序操作：**

1. 先点击网页中的 **“连接并读取语音”**，等待出现退出 / 重新打开微信的提示。
2. 在 Windows 右下角找到微信托盘图标，通过菜单 **“退出微信”**。仅关闭聊天窗口不会退出进程。
3. 手动重新打开微信并登录刚才选择的账号。
4. 保持本工具终端和网页运行，等待它自动继续。

获取等待上限为 5 分钟，可以点击 **“取消”**。工具不会自动结束微信，也不会代替你登录；因此首次获取可能需要上述手动操作，不能保证全程只点一个按钮。

### 3. 确认连接完成

成功后顶部显示 **“已连接本机微信”** 和更新时间，左侧出现会话，页面显示语音数量。点击 **“收起”** 回到列表。

工具会保存成功的连接配置，下次启动时直接读取已准备的数据。失败或取消时，之前成功加载的列表会保留；第一次连接失败时仍是空列表。

## 先导出一条语音试试

1. 在左侧搜索并选择一个群聊或联系人。
2. 先将 **“发送人”** 设为 **“全部发送人”**，清除日期筛选，避免把目标语音过滤掉。
3. 点击某条语音左侧的试听按钮。首次试听需要按需转换，等待片刻。
4. 点击该条右侧的 **“下载”**，得到 MP3。具体保存位置取决于浏览器下载设置。
5. 用系统播放器打开下载的文件，确认能正常播放。

**成功标准：** 不需要在微信里播放该消息，也能在独立播放器中听到导出的 MP3。

自己和他人发送的语音都可以提取，前提是电脑里存在对应原始媒体。目前发送者显示为备注、昵称或账号，不一定标成“我”；无法精确关联的显示为“未知发送人”。

### 批量导出

单条确认正常后，再按发送人、开始日期、结束日期和时间顺序筛选，点击 **“导出当前 N 条”**。

- 网页日期范围包含起止当天，按北京时间处理。
- 导出范围是全部筛选结果，包含后续分页，不仅是当前屏幕上的几条。
- 完成后点击进度区域的 **“打开文件夹”** 找到结果。
- 批量结果默认位于项目的 `exports/` 下，包含 MP3、原始语音和 `manifest.json` 清单。
- 点击“取消”会停止后续处理，已经完成的批量导出文件会保留。

## 可选：在 Android App 中整理语音

**只需要 MP3 时，可以跳过这一节。** 直接把导出的 MP3 传到手机，用普通播放器打开即可。

如果希望在手机上保留会话分类、发送人和日期筛选，再使用“语音档案”App。目前 App 版本为 0.2.0，最低支持 Android 10，已在 Android 16 真机验证。

### 1. 准备 App

当前提供源码构建方式；`build/voice-library-debug.apk` 是构建后在本机生成的文件，不是源码仓库中自带的下载文件。

构建需要 JDK 17、Android SDK Platform 34 和 Build Tools 34.0.0。安装这些工具后，在项目目录运行下列命令，并将两个路径换成自己的安装位置：

```powershell
& '.\scripts\Build-LibraryApk.ps1' -JdkPath 'C:\Program Files\Java\jdk-17' -SdkPath 'D:\Android\Sdk'
```

如果已经正确设置 `JAVA_HOME` 和 `ANDROID_SDK_ROOT`，也可以直接运行：

```powershell
& '.\scripts\Build-LibraryApk.ps1'
```

成功后，将 `build/voice-library-debug.apk` 传到手机安装。按手机系统提示允许该次安装。

构建时会生成本机开发签名。后续更新 App 请保留同一套 `build/library-debug.keystore`，避免签名不一致导致无法覆盖更新。

### 2. 从网页生成手机数据包

1. 在电脑网页选择会话，按需筛选发送人和日期。
2. 点击 **“生成手机数据包”**，等待进度完成。
3. 点击 **“打开文件夹”**，找到生成的 `.voicepack.zip` 文件。
4. 用 USB 或文件传输工具，将这个 ZIP 传到手机，例如 `Download` 目录。

### 3. 在 App 中导入与保存

1. 打开手机上的 **“语音档案”**。
2. 点击 **“导入”**，或进入 **“数据管理 → 导入语音数据包”**。
3. 在系统文件选择器中选择刚传来的 ZIP，**无需解压**。如果“最近”找不到，进入 `Download` 目录查找。
4. 导入完成后进入会话，即可离线按日期、发送人和时间顺序查找与试听。
5. 点击 **“多选”**，勾选语音后保存；也可保存当前筛选结果。

导出的 MP3 保存在手机 **`Music/VoiceKeep/会话目录/`**。使用文件管理器进入手机内部存储的 `Music → VoiceKeep` 查找。

重复导入会跳过已有语音，并补齐缺失或损坏的音频；相同且完整的公共 MP3 重复保存时会跳过。当前支持前台连续播放，离开 App 会暂停。

App 不申请录音、联网或所有文件访问权限。导入后的浏览、筛选和播放不需要电脑持续连接，但增加新的微信语音仍需电脑生成新数据包。

## 以后再次使用

通常只需以下步骤，不需要重复安装依赖：

1. EXE 用户双击程序，网页会自动打开。源码用户在项目文件夹运行 `scripts/Start-VoiceLibrary.ps1`。
2. 电脑微信有新聊天时，点击顶部 **“刷新聊天数据”**，等待成功后继续筛选和导出。
3. 需要更换账号或目录时，进入顶部 **“数据源设置”**。
4. 需要更新手机内容时，重新生成数据包、传到手机并导入。

如果修改了网页服务端代码或重新启动过服务，请刷新浏览器页面再操作。

## 常见问题

| 遇到的问题 | 处理方式 |
| --- | --- |
| 网页打不开 | EXE 用户点击小窗口“打开网页”，以窗口显示的地址为准；源码用户确认启动终端仍在运行且没有报错。不要在手机上打开这个本机地址 |
| 8766 端口被占用 | EXE 会自动换端口；源码用户先停止重复启动的终端，也可运行 `& '.\scripts\Start-VoiceLibrary.ps1' -Port 8767`，然后打开 `http://127.0.0.1:8767/` |
| 找不到账号 / 检查目录失败 | 在微信设置核对实际聊天数据位置，选择 `xwechat_files`、账号目录或 `db_storage`；不要选安装目录或 `Backup`，并确认不是旧版数据格式 |
| 一直等待微信退出 | 通过右下角微信托盘菜单退出，关闭聊天窗口不等于退出进程 |
| 密钥获取超时或失败 | 等待本次任务结束或取消，确认所选账号和微信版本，再点击连接并按页面提示重登；不要将密钥粘贴到网页 |
| 显示“请求无效” | 服务重启后旧页面的会话会失效，刷新整个网页再试 |
| 刚收到的语音没显示 | 等待电脑微信完成接收，再点击“刷新聊天数据”；列表不是实时监听微信 |
| 某条历史语音或自己发送的语音不见了 | 先清除发送人和日期筛选；仍没有时，检查该语音是否只在手机上，或电脑中只有消息记录而没有原始媒体 |
| 手机导入时找不到 ZIP | 把完整 ZIP 传到 `Download`，在系统文件选择器进入该目录；不要解压，也不要只传其中的 MP3 |
| 手机不能读取微信 / 微信登录后没有自动出现记录 | 这是当前能力范围：App 读取的是导入的数据包，微信登录授权不提供聊天记录访问能力 |
| 项目占用空间持续增加 | 每次刷新会生成独立数据副本，旧副本暂不自动清理；连接前确认项目所在磁盘有足够空间 |

如果需要报告问题，请提供操作步骤、Windows / 微信版本和页面报错文字，去掉个人账号、路径及聊天内容，不要附上真实密钥或数据库。

## 本机文件保存在哪里

EXE 用户的下列数据路径位于 `%LOCALAPPDATA%\VoiceKeep`；源码用户位于项目目录。`build/` 下的 APK 与签名只在源码构建时生成。

| 位置 | 内容 |
| --- | --- |
| `.private/connection.json` | 上次成功连接的数据源配置 |
| `.private/connections/` | 密钥、解密副本与按需 MP3 缓存 |
| `exports/` | 批量导出结果和手机数据包 |
| `build/voice-library-debug.apk` | 本机构建的 Android 试用安装包 |
| `build/library-debug.keystore` | 本机 Android 开发签名，后续覆盖更新需要保留 |
| 手机 `Music/VoiceKeep/` | App 保存到公共目录的 MP3 |

`.private/` 中包含敏感数据，不要上传或分享。手机数据包也包含语音和会话元数据，请只传给需要使用的设备。这些本机产物均不随源码提交到 Git。

### 开发者自行构建 EXE

完成上方源码安装和固定版本依赖下载后：

```powershell
& '.\.venv\Scripts\python.exe' -m pip install -r requirements-build.txt
& '.\scripts\Build-DesktopExe.ps1'
```

产物为 `build/desktop-dist/VoiceKeep.exe`。打包文件清单采用白名单，不包含开发者的微信数据、密钥或导出文件。具体结构与验证方法见 [Windows EXE 说明](docs/windows-exe.md)。
